# AGENTS.md

This repository is the source of the agent instructions and `.editorconfig` that the zencq .NET repositories share; `README.md` explains the layers and the sync. The files in `instructions/` are not instructions for this repository: they are synced into the others.

When you work here, follow [instructions.instructions.md](instructions/dotnet/instructions.instructions.md) for writing the shared files, [workflows.instructions.md](instructions/dotnet/workflows.instructions.md) for `.github/workflows/`, and [commits.instructions.md](instructions/dotnet/commits.instructions.md) for commits.
