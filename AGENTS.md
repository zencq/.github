# AGENTS.md

This repository is the source of the agent instructions and repository setup files that the zencq repositories share; `docs/README.md` explains the layers, the sync, and the scripts. The files in `instructions/` are not instructions for this repository: they are synced into the others.

When you work here, follow [instructions.instructions.md](instructions/common/instructions.instructions.md) for writing the shared files, [workflows.instructions.md](instructions/common/workflows.instructions.md) for `.github/workflows/`, [dependabot.instructions.md](instructions/common/dependabot.instructions.md) for `.github/dependabot.yml`, [commits.instructions.md](instructions/common/commits.instructions.md) for commits and branches, [names.instructions.md](instructions/common/names.instructions.md) for repository names, and [qlty.instructions.md](instructions/common/qlty.instructions.md) for Qlty.
